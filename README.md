# Салон красоты «Мадонна» — лендинг

Одностраничный сайт салона красоты «Мадонна» (Люберцы, 900 м от метро Котельники).

**Весь сайт — один файл [`index.html`](index.html).** Ни сборщика, ни зависимостей: HTML, CSS и JS
лежат внутри. Файл открывается двойным кликом и работает. Логотип и иконки вшиты как data-URI,
поэтому сайт можно переслать одним файлом.

Внешними остаются только Google Fonts (Playfair Display + Inter) и iframe Яндекс.Карт.

## Как запустить

Открыть `index.html` в браузере. Для публикации — залить файл на любой хостинг
или включить GitHub Pages в настройках репозитория (Settings → Pages → Deploy from branch → `main` / root).

## Что нужно заменить перед запуском

| Что | Где | Зачем |
|---|---|---|
| **Фотографии** | 24 блока `.photo-slot` | Сейчас плейсхолдеры. В каждом подписан нужный формат и размер, например «ФОТО: интерьер зала, горизонталь 3:2, 1600×1067». Заменяются на `<img>`; классы соотношений `.ps-3x2`, `.ps-4x5`, `.ps-1x1` уже готовы. Галерея работ собирается из массива `GALLERY` в JS. |
| **Ссылка на онлайн-запись** | `SITE_CONFIG.bookingUrl` в начале `<script>` | Уже заполнена — карточка салона на Яндекс.Картах с параметром `booking[page]=menu`, открывающим расписание мастеров (YCLIENTS). Сюда ведут **все** кнопки «Записаться», поэтому адрес меняется одной строкой. Если появится прямая ссылка на виджет YCLIENTS — вписать её же сюда. |
| **Яндекс.Метрика** | закомментированный блок в `<head>` | Подставить номер счётчика вместо `XXXXXXXX` (два места) и раскомментировать. |
| **Координаты и часы** | JSON-LD в `<head>` | `latitude`/`longitude` стоят приблизительные, час открытия в `openingHours` указан как 09:00 — уточнить фактический. |
| **`og:image`** | `<head>` | Тега нет: нужен абсолютный URL картинки 1200×630 после публикации на домене. Без него в мессенджерах будет пустая карточка. |
| **Политика данных** | модалка внизу страницы | Сайт не собирает персональные данные — форм на нём нет, запись идёт по ссылкам. Текст описывает только cookie и Метрику. Если подключите счётчики, покажите его юристу. |
| **Логотип в векторе** | CSS-правило `.brand-mark`, блок фавиконки в `<head>` | Текущий исходник — JPG 640×640, у буквы «M» срезаны края, на 16–32px фавиконка читается плохо. В `<head>` лежит закомментированная резервная SVG-монограмма — переключается одной правкой. |

## Что уже сделано

- Адаптив: брейкпоинты 1180 / 1080 / 900 / 640, проверено на 375–1440px без горизонтального скролла.
- Доступность: `focus-visible`, `aria-label` на бургере, аккордеонах, лайтбоксе и вкладках прайса,
  осмысленные `alt`/`aria-label` у всех плейсхолдеров, `prefers-reduced-motion` отключает анимации.
- SEO: `<title>` и `description` с гео-привязкой, OG-теги, JSON-LD `BeautySalon`
  с адресом, телефоном, часами и рейтингом 5,0 (190 оценок).
- Запись без форм: все кнопки ведут в живое расписание, рядом — Telegram, телефон и карточка на Яндекс.Картах.
- Липкая панель «Записаться · Позвонить» на мобильном, уезжает над блоком записи.
- Никакого localStorage/sessionStorage, никаких всплывающих окон при заходе.

## Мастера

Состав сверен с отзывами на Яндекс.Картах — все семеро упоминаются там поимённо:
Марина (колорист), Жанна (маникюр и педикюр), Тамара (педикюр), Владислава (маникюр),
Ксения (брови), Лолита (косметолог), Анаит (администратор). Восьмая, Мадонна —
специалист лазерной эпиляции — взята из списка специалистов в онлайн-записи YCLIENTS.
